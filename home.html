About the Search Engine

Search returns every index entry whose keyword phrase starts with your query as whole words, ignoring case ("index" finds "index", not "indexing"). The index is built by abstract data types on the server: Input, Line Storage, Circular Shift (with noise elimination), Alphabetizer and Output, run one line at a time by Master Control.
